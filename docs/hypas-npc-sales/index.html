COMMON QUESTIONS

Know what you're installing.

Is every NPC sale guaranteed?

No. A transaction may be rejected, negotiated, interrupted, reported or turn into a robbery depending on the configured conditions.

Does progression survive restarts?

Yes. Dealer statistics, reputation, personal heat and transaction history can be persisted using a supported SQL driver.

Is an additional target framework required?

The current listing specifies VORP Core and vorp_inventory. oxmysql is recommended; ox_target and ox_lib are not required.

Where can I configure prices and items?

Server owners can edit the supplied configuration and framework bridge, including supported goods, probabilities, heat, demand and interface settings.
